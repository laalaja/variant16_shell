# Эмулятор UNIX-подобной оболочки — вариант 16

Учебный проект по дисциплине «Конфигурационное управление».
Программа предоставляет графический эмулятор командной строки и работает
с виртуальной файловой системой, загружаемой из JSON.

## Этап 5. Команда `mkdir`

На этом этапе к полностью работающим командам этапа 4 добавлена команда
`mkdir`. Она создаёт директории только в оперативной памяти. Исходный
JSON-файл виртуальной файловой системы не изменяется.

## Возможности

- графический интерфейс на Tkinter;
- имя VFS и текущий путь в приглашении командной строки;
- простой парсер команд по пробелам;
- параметры запуска `--vfs` и `--script`;
- выполнение стартового скрипта до первой ошибки;
- загрузка VFS из JSON;
- навигация по абсолютным и относительным путям;
- команды `ls`, `cd`, `cal`, `head`, `tac`, `mkdir`, `exit`;
- изменения VFS только в памяти;
- автоматические тесты.

## Запуск

На Windows:

```bat
run.bat
```

На Linux/macOS:

```sh
./run.sh
```

Запуск вручную:

```bat
python src\main.py --vfs fixtures\vfs_demo.json
```

Запуск со стартовым скриптом:

```bat
python src\main.py --vfs fixtures\vfs_demo.json ^
  --script scripts\startup_all.txt
```

## Команды

### `ls [PATH]`

Показывает содержимое текущей или указанной директории.

### `cd PATH`

Переходит в другую директорию. Поддерживаются `/`, `.`, `..`, абсолютные
и относительные пути.

### `cal [MONTH] [YEAR]`

Без аргументов показывает текущий месяц. С одним аргументом показывает
указанный год, с двумя — указанный месяц указанного года.

### `head [-n COUNT] FILE`

Показывает первые 10 строк файла либо первые `COUNT` строк.

### `tac FILE`

Показывает строки файла в обратном порядке.

### `mkdir DIRECTORY`

Создаёт одну директорию в VFS. Родительская директория должна существовать.
Нельзя перезаписать уже существующий файл или каталог. Изменение сохраняется
только до завершения программы.

### `exit`

Закрывает приложение.

## Пример проверки `mkdir`

```text
ls
mkdir projects
ls
cd projects
mkdir drafts
ls
cd /
mkdir home
mkdir missing/child
```

Первые две команды `mkdir` должны успешно создать каталоги. Команда
`mkdir home` должна сообщить, что объект уже существует, а последняя команда
— что родительский путь не найден.
