# Эмулятор UNIX-подобной оболочки — вариант 16

Учебная работа по дисциплине «Конфигурационное управление».
Программа реализует графический эмулятор командной строки, работающий
с виртуальной файловой системой (VFS), загружаемой из JSON.

## Что реализовано

- GUI на Tkinter.
- Имя VFS в заголовке окна.
- Простой парсер: команда и аргументы разделяются пробелами.
- Обработка неизвестных команд и неверных аргументов.
- Параметры запуска `--vfs` и `--script`.
- Стартовый скрипт останавливается при первой ошибке.
- VFS загружается из JSON и изменяется только в памяти.
- Поддержка текстовых файлов и base64 для двоичных данных.
- Команды `ls`, `cd`, `cal`, `head`, `tac`, `mkdir`, `exit`.
- Несколько VFS разного размера и глубины вложенности.
- BAT/SH-скрипты для проверки параметров запуска.
- Unit-тесты.

## Запуск

### Windows

```bat
run.bat
```

Или напрямую через Python:

```bat
python src\main.py --vfs fixtures\vfs_demo.json
```

Запуск со стартовым скриптом:

```bat
python src\main.py --vfs fixtures\vfs_demo.json ^
  --script scripts\startup_all.txt
```

### Linux/macOS

```sh
./run.sh
```

## Параметры запуска

- `--vfs` — путь к JSON-файлу виртуальной файловой системы.
- `--script` — путь к стартовому скрипту с командами эмулятора.

Если передан стартовый скрипт, команды выполняются последовательно.
При первой ошибке выполнение скрипта прекращается.

## Команды эмулятора

### `ls [PATH]`

Показывает содержимое текущей или указанной директории.

### `cd PATH`

Переходит в другую директорию VFS. Поддерживаются `/`, `.`, `..`.

### `cal [YEAR]` и `cal MONTH YEAR`

Выводит календарь текущего месяца, указанного года или указанного месяца и года.

### `head [-n N] FILE`

Показывает первые 10 строк файла либо первые `N` строк.

### `tac FILE`

Показывает строки файла в обратном порядке.

### `mkdir DIRECTORY`

Создаёт директорию в виртуальной файловой системе. Изменение существует
только в памяти и не изменяет исходный JSON-файл.

### `exit`

Закрывает приложение.

## Формат VFS

Пример JSON-файла виртуальной файловой системы:

```json
{
  "name": "demo-vfs",
  "root": {
    "type": "dir",
    "children": {
      "hello.txt": {
        "type": "file",
        "encoding": "text",
        "content": "Hello"
      }
    }
  }
}
```

Для двоичных данных используется значение `"encoding": "base64"`.

Все операции над VFS после загрузки выполняются в оперативной памяти.
Исходный JSON-файл не изменяется.
