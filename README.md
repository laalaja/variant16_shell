# Эмулятор командной оболочки — вариант 16

## Этап 2. Конфигурация

Реализован прототип эмулятора UNIX-подобной командной оболочки
с графическим интерфейсом и поддержкой параметров запуска.

## Возможности

- графический интерфейс на Tkinter;
- имя VFS отображается в заголовке окна;
- простой парсер команд по пробелам;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- обработка неизвестных команд и неверных аргументов;
- параметр командной строки `--vfs`;
- параметр командной строки `--script`;
- выполнение стартового скрипта;
- остановка стартового скрипта при первой ошибке;
- вывод параметров конфигурации при запуске.

## Запуск

На Windows:

```bash
run.bat
```

Или вручную:

```bash
python src/main.py --vfs demo-vfs
```

Запуск со стартовым скриптом:

```bash
python src/main.py --vfs demo-vfs --script scripts/startup_ok.txt
```

Проверка остановки при ошибке:

```bash
scripts/test_startup.bat
```

## Примеры команд

```text
ls
cd home
exit
```

На данном этапе `ls` и `cd` являются командами-заглушками.
Полноценная работа с виртуальной файловой системой будет добавлена
на следующем этапе.
